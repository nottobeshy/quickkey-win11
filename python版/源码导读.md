# 键游 Python 版源码导读

界面与交互源码位于 [quickkey.pyw](./quickkey.pyw)，官方快捷键数据位于 [shortcuts_catalog.py](./shortcuts_catalog.py)。`.pyw` 仍然是普通、可编辑的 Python 源码，只是在 Windows 上双击运行时不会弹出黑色控制台窗口。

## 源码结构

源文件按阅读顺序分成七个部分，每一部分和关键逻辑都带有中文注释：

1. **视觉常量**：窗口尺寸，以及暗色明日香机甲舱配色。
2. **课程数据**：8 个核心快捷键的标题、组合键、提示和三步训练内容。
3. **本地进度**：使用 JSON 保存积分、连续天数与掌握状态。
4. **全局键盘钩子**：用 `ctypes` 调用 Windows `WH_KEYBOARD_LL`，在其他窗口中也能识别按键。
5. **自定义控件**：按钮悬停、HUD 进度条等可复用组件。
6. **主应用**：训练页、快捷键总览、成就页、悬浮球、音效、抖动和彩纸。
7. **启动与自检**：正常启动入口，以及无需打开窗口的 `--check` 检查。

## 新增的快捷键总览

点击底部的“总览”可以看到微软官方 Windows 11 快捷键主目录，共 228 条记录：

- 覆盖 Copilot 键、文本编辑、桌面与常规、Windows 键、命令提示符、对话框、文件资源管理器、虚拟桌面、任务栏和设置；
- 支持按组合键、动作说明和类别搜索；
- 支持类别下拉筛选和鼠标滚轮；
- 会锁屏、关闭、永久删除或管理员启动的条目标记为“⚠ 谨慎”；
- 只在特定窗口或硬件中生效的条目标记为“场景限定”；
- 8 个核心项目可以点击并立即跳到分步训练，其他项目安全地只展示说明。

目录核对来源是 [Microsoft Support：Windows 的键盘快捷方式](https://support.microsoft.com/zh-cn/windows/windows-%E7%9A%84%E9%94%AE%E7%9B%98%E5%BF%AB%E6%8D%B7%E6%96%B9%E5%BC%8F-dcc61a57-8ff0-cffe-9796-cb9706c75eec)，核对日期为 2026-07-16。
